# Stack da aplicação

Backend usa Java 21 e Spring Boot 3; frontend usa Next.js com TypeScript e SSR. PostgreSQL 16 é a persistência relacional. Esta decisão substitui referências ativas a NestJS/Prisma como stack normativa.
