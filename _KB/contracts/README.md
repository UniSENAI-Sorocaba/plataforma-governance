# Política de contratos

IDs seguem `CONTRACT-<DOM>-NNN`. Contratos globais residem aqui; contratos locais podem permanecer no produtor se referenciados por versão. OpenAPI 3.1 governa APIs síncronas, AsyncAPI eventos e JSON Schema payloads. Breaking changes incrementam MAJOR e exigem compatibilidade/migração documentada.
