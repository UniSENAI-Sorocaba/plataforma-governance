# Git e Pull Requests

Usar GitHub Flow: branch curta → PR → `main`. Sem `develop` ou `release/*` padrão, push direto ou force push. Checks, CODEOWNERS e conversas resolvidas são obrigatórios. Releases partem de commits aprovados de `main` por tags protegidas. PR referencia Issue, SPEC/baseline, testes, riscos e rollback.
