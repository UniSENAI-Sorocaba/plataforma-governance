# Padrões de engenharia

Código deve ser legível, testável, modular e observável; não conter secrets; respeitar contratos, ADRs e Must Haves. Backend usa Java 21/Spring Boot 3; frontend usa TypeScript/Next.js SSR. Formatação/lint são automáticos e PRs pequenos seguem `git-and-pr.md`.
