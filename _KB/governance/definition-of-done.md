# Definition of Done

- [ ] critérios de aceite atendidos e evidenciados;
- [ ] testes, lint, build e análises estáticas aprovados;
- [ ] contratos, ADRs e Must Haves respeitados;
- [ ] `spec-compliance` sem FAIL e WARNs justificados;
- [ ] revisão de código e CODEOWNERS aprovadas;
- [ ] documentação e rollback atualizados quando aplicável;
- [ ] PR merged e validação pós-merge concluída;
- [ ] aceite do PO quando a entrega exige homologação funcional.
