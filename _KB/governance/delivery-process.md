# Processo de entrega

Cadência quinzenal: refinamento semanal, planning no início, daily por squad, review e retrospectiva no encerramento. O modelo é híbrido: squads funcionais possuem ownership permanente, enquanto épicos atravessam múltiplas squads. Dependências são registradas no Project e tratadas no refinamento conjunto de líderes.

Fluxo: `Backlog → Refinement → Ready → In Progress → In Review → Validation → Done`, com `Blocked` como exceção explícita.
