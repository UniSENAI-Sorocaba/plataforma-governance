# Must Haves — Security

- `MH-SEC-001`: senhas nunca são armazenadas em texto puro.
- `MH-SEC-002`: autorização é validada server-side.
- `MH-SEC-003`: secrets não são versionados no Git.
- `MH-SEC-004`: credenciais e tokens sensíveis não aparecem em logs.
