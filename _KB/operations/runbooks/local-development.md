# Desenvolvimento local

Clone apenas os repositórios necessários, fixe a baseline, instale versões declaradas por cada repo, copie `.env.example` sem secrets reais, suba dependências por containers e execute healthchecks, migrations e testes. Comandos concretos pertencem ao README do repositório executor.
